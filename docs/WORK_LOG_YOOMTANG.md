## 2026-07-05

매장 등급이 매출, 리뷰, 평점, 주문수를 종합해서 자동으로 올라가게 만들었어요. 매출이 늘거나 리뷰가 늘거나 주문이 늘면 그때그때 등급이 다시 계산돼요.

화면에서도 새 등급 이름(DÉBUT~EMPIRE)이 제대로 보이게 고쳤어요. 다음 등급이 뭔지도 화면에 살짝 보여요.

PC 화면에서 보이는 사이드바 메뉴를 새로 만들었어요. 모바일에서는 기존 화면 그대로 보여요.

화면 맨 아래 있던 탭 메뉴를 없앴어요. 이제 PC에서는 왼쪽 사이드바로 이동해요. 모바일 메뉴는 다음에 따로 정리할게요.

모바일에서는 원래처럼 하단 메뉴바가 그대로 보이고, PC에서만 왼쪽 사이드바가 떠요. 네이버 스토어랑 같은 방식이에요.

하단 메뉴가 엉뚱한 옛날 주소를 보고 있던 걸 고쳤어요. 이제 탭 누르면 정확한 페이지로 가고, 탭이 두 번 겹쳐 보이던 것도 없앴어요.

안 쓰는 옛날 폴더(salon)를 완전히 지웠어요. 이제 원장 콘솔은 owner 경로 하나로 깔끔하게 정리됐어요.

브랜드 관련 화면 5개도 하단 메뉴가 정확한 주소로 가게 고쳤어요. 이제 원장 콘솔 전체에서 탭바가 다 제대로 작동해요.

라이브랑 반품 화면에서 브랜드 목록이 항상 안 보이던 버그를 찾아서 고쳤어요. 이제 정상적으로 내가 거래하는 브랜드가 다 보여야 해요.

고객/원장/파트너/브랜드 정보가 저장되는 방식을 하나하나 점검했어요. 같은 정보가 두 군데 저장돼서 헷갈릴 뻔한 부분들을 정리하고, 앞으로 실수 안 하게 규칙을 문서로 만들어뒀어요. (전화번호 동기화는 다음에 마저 손볼 예정)
